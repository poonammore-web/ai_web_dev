The Story

How It All Started

From a blank scaffold to a fully functional website — using only Amazon Q.

1
We Had a Blank Starter

The project started with just a Bootstrap scaffold — a basic index.html with a navbar, a card, and a click counter button in app.js. Nothing special. Just boilerplate.

2
We Opened Amazon Q in VS Code

Amazon Q Developer is an AI assistant built by AWS that runs directly inside your IDE. We used the chat panel to describe what we wanted — in plain English, like talking to a colleague.

3
Amazon Q Wrote All the Code

Every line of HTML, CSS, and JavaScript was generated by Q. We never opened a code editor to type — we just described what we wanted, Q wrote it, and we accepted the changes.

4
We Iterated with More Prompts

"Make it simpler." "Add dark mode." "Add a password generator." "The moon button isn't working." Each time, Q diagnosed, fixed, or added exactly what was needed — instantly.

5
Q Even Handled Git & GitHub

We asked Q to push our code to GitHub. It found Git on our system, fixed the PATH issues, set environment variables, committed our code, and pushed to our remote repo — all from the chat panel.

Dark Mode Toggle 
const themeToggle = document
  .getElementById("themeToggle");

themeToggle.addEventListener("click", () => {
  const html = document.documentElement;
  const isDark = html
    .getAttribute("data-bs-theme") === "dark";

  // Set Bootstrap dark mode
  html.setAttribute("data-bs-theme",
    isDark ? "light" : "dark");

  // Set custom CSS variables
  html.setAttribute("data-theme",
    isDark ? "light" : "dark");

  // Swap icon
  themeToggle.innerHTML = isDark
    ? '<i class="bi bi-moon-fill"></i>'
    : '<i class="bi bi-sun-fill"></i>';
});

  .addEventListener("click", () => {
  const len = +pwLength.value;
  let chars = "abcdefghijklmnopqrstuvwxyz";

  // Generate random password
  const pw = Array.from({ length: len },

  if (syms.checked)  strength++;
});

Scroll Fade-in Animation 
// IntersectionObserver for fade-up
const fadeObserver = new IntersectionObserver(
  (entries) => {
    entries.forEach(({ target, isIntersecting }) => {
      if (isIntersecting) {
        target.classList.add("visible");
        fadeObserver.unobserve(target);
      }
    });
  },
  { threshold: 0.1 }
);

// Apply to all cards
document.querySelectorAll(
  ".feature-card, .demo-card, .testimonial-card"
).forEach(el => {
  el.classList.add("fade-up");
  fadeObserver.observe(el);
});
